# NHN Bastion으로 SSH 접근 통제 구성하기

## 시작하기 전에

NHN Bastion은 NHN Cloud 인스턴스에 대한 SSH(Secure Shell) 접근을 중앙에서 통제하는 서버 접근 제어 서비스입니다. 브라우저 기반 웹 터미널을 제공하므로 별도의 터미널 프로그램 없이 인스턴스에 접속할 수 있으며, NHN Cloud 콘솔의 사용자 인증 및 다중 인증(MFA)과 결합되어 보안을 강화할 수 있습니다.

NHN Bastion의 접근 통제 정책을 설정하면 사용자별로 접속 가능한 인스턴스를 제한하고 특정 명령어의 사용을 허용하거나 금지할 수 있으며, 접속 이력과 명령어 사용 이력이 자동으로 기록되어 보안 감사에 활용할 수 있습니다. 프로젝트 내 인스턴스의 생성이나 삭제, 오토스케일링 인/아웃이 접근 대상에 자동으로 반영되어 별도의 등록 작업 없이 운영할 수 있습니다.

여기에서는 NHN Bastion 서비스를 활성화하고 웹 터미널을 생성한 뒤, 접근 통제 대상 인스턴스를 등록하고, 사용자별 접근 통제 정책과 명령어 통제 정책을 설정하고, 웹 터미널로 인스턴스에 접속하고 접속 이력을 확인하는 흐름을 살펴봅니다.

## 시나리오 환경 구성

가이드를 따라하려면 다음 준비가 필요합니다.

- 접근 통제 대상이 될 인스턴스가 하나 이상 생성되어 있어야 합니다.
- 대상 인스턴스의 SSH 키 또는 비밀번호 인증 정보를 준비합니다.

## NHN Bastion 서비스 활성화하기

NHN Bastion은 다른 서비스와 달리 활성화할 때 API 연동 권한 동의와 웹 터미널 생성이 함께 이루어집니다. 웹 터미널은 브라우저에서 인스턴스에 SSH로 접속할 때 중간 경유지 역할을 하는 인스턴스입니다.

### 서비스 활성화

1. NHN Cloud 콘솔 상단의 **서비스 선택**을 클릭하세요.

2. 서비스 목록에서 **NHN Bastion**을 클릭하세요. 서비스 활성화 확인 모달 창이 나타납니다.

3. NHN Bastion은 서비스 제공을 위해 API 연동으로 사용자 리소스에 접근하는 권한이 필요합니다. **동의** 체크박스를 선택한 뒤 **확인**을 클릭하세요.

    서비스가 활성화되면 **웹 터미널 생성** 화면이 자동으로 나타납니다.

### 웹 터미널 생성

웹 터미널 생성을 완료해야 NHN Bastion 서비스를 이용할 수 있습니다.

1. 웹 터미널 생성 화면에서 각 항목을 설정합니다.

    - **이름***: 웹 터미널을 구분할 이름을 입력합니다. 여러 웹 터미널을 운영할 수 있으므로 용도를 알 수 있는 이름이 좋습니다.
    - **가용성 영역***: 웹 터미널 인스턴스가 생성될 가용성 영역을 선택합니다.
    - **타입***: 웹 터미널의 인스턴스 타입을 선택합니다. 타입에 따라 동시에 생성할 수 있는 SSH 세션 수가 달라집니다. m2.c2m4(최대 35세션)는 소규모, m2.c4m8(최대 100세션)은 중규모, m2.c8m16(최대 300세션)은 대규모 인프라에 적합합니다.
    - **VPC***: 웹 터미널에서 사용할 VPC를 선택합니다. 접속 대상 인스턴스와 SSH 통신이 가능한 VPC를 선택해야 합니다.
    - **서브넷***: 선택한 VPC 내 서브넷을 선택합니다.
    - **플로팅 IP***: 웹 터미널에 플로팅 IP를 할당할지 선택합니다. 인터넷 게이트웨이가 연결된 VPC에서만 플로팅 IP를 사용할 수 있습니다.
    - **암호화***: 접근 이력과 명령어 이력을 암호화할지 선택합니다. 사용하려면 사전에 Secure Key Manager 서비스에서 대칭 키를 생성해야 합니다.
    - **DB 이중화***: 이력을 저장하는 DB를 이중화하여 고가용성을 제공합니다.

2. 설정을 확인한 뒤 **웹 터미널 생성**을 클릭하세요. 생성 정보 확인 모달 창이 나타납니다.

3. 내용을 확인하고 **웹 터미널 생성**을 클릭하세요. 웹 터미널 인스턴스 생성이 시작되며, 완료까지 수 분이 걸릴 수 있습니다.

> [!WARNING]
> 최초 생성된 웹 터미널은 NHN Bastion 서비스를 비활성화할 때까지 삭제할 수 없습니다. 타입과 VPC를 신중하게 선택하세요.

> [!NOTE]
> 웹 터미널과 접속 대상 인스턴스 간에 SSH 통신(기본 포트 22)이 가능해야 합니다. 대상 인스턴스의 보안 그룹(Security Groups)에서 웹 터미널 IP의 인바운드 SSH 트래픽을 허용했는지 확인하세요.

### IP 접근 제어 설정

웹 터미널은 **IP 접근 제어**(화이트리스트 방식)가 적용되어 있어, 허용된 IP에서만 웹 터미널에 접속할 수 있습니다. 기본적으로 웹 터미널의 서브넷 대역만 등록되어 있으므로, 브라우저에서 접속하려면 사용자 PC의 공인 IP를 추가해야 합니다.

1. NHN Cloud 콘솔에서 **Security > NHN Bastion**을 클릭하세요.

2. **자원 관리** > **웹 터미널 관리** 탭을 클릭하세요.

3. 웹 터미널 행의 **관리**(⋮) 버튼을 클릭한 뒤 **IP 접근 제어**를 선택하세요.

4. **+** 버튼을 클릭해 행을 추가한 뒤, **CIDR**에 사용자 PC의 공인 IP를 CIDR 형식으로 입력합니다.

5. **저장**을 클릭하세요.

> [!WARNING]
> IP 접근 제어를 설정하지 않으면 웹 터미널에 접속할 때 "사이트에 연결할 수 없음" 오류가 발생합니다. 접속 문제가 발생하면 가장 먼저 IP 접근 제어 설정을 확인하세요.

## 접근 통제 대상 인스턴스 등록하기

NHN Bastion에서 접근을 통제하려면 먼저 대상 인스턴스를 등록해야 합니다.

1. NHN Cloud 콘솔에서 **Security > NHN Bastion**을 클릭하세요.

2. **자원 관리** > **인스턴스 관리** 탭을 선택하세요.

3. **+ 추가**를 클릭하세요. 프로젝트에 생성된 인스턴스 목록이 표시됩니다.

4. 접근 통제 대상으로 등록할 인스턴스를 선택한 뒤 **추가**를 클릭하세요.

    등록이 완료되면 인스턴스 관리 목록에 해당 인스턴스가 나타납니다.

> [!NOTE]
> **자동 등록**을 활성화하면 프로젝트 내 모든 인스턴스가 자동으로 등록되며, 인스턴스 생성이나 삭제 시에도 자동으로 반영됩니다.

## 접근 통제 정책 설정하기

접근 통제 정책은 어떤 사용자가 어떤 인스턴스에 접근할 수 있는지, 어떤 명령어를 사용하거나 사용하지 못하는지를 정의합니다. 정책은 우선순위가 있으며, 높은 우선순위부터 적용됩니다.

1. NHN Cloud 콘솔에서 **Security > NHN Bastion**의 **정책 관리** 탭을 클릭하세요.

2. **+ 정책 생성**을 클릭하세요.

3. **정책 정보**에서 정책의 이름과 설명을 입력합니다.

    - **이름**: 정책의 용도를 알 수 있는 이름을 입력합니다.
    - **설명**: 정책의 목적을 간략히 입력합니다.

4. **사용자 및 그룹**에서 이 정책을 적용할 접근 주체를 등록합니다.

    **+ 추가**를 클릭하면 **사용자 및 그룹 추가** 모달 창이 나타나고, NHN Bastion 서비스 권한이 있는 사용자 목록이 표시됩니다. 접근을 허용할 사용자를 선택한 뒤 **추가**를 클릭합니다. 미리 사용자 그룹을 만들어 두었다면 그룹 단위로도 등록할 수 있습니다.

5. **자원 및 자원 그룹**에서 접근 대상을 지정합니다.

    - **모든 자원**: 등록된 모든 인스턴스에 접근을 허용합니다.
    - **자원 선택**: 특정 인스턴스, 오토스케일링 그룹, 자원 그룹만 접근 대상으로 지정합니다.

    보안 요건에 맞게 적절한 범위를 선택하세요. 운영 환경에서는 **자원 선택**으로 필요한 인스턴스만 지정하는 것을 권장합니다.

6. **명령어 통제 정책**에서 명령어 사용 범위를 설정합니다.

    - **허용**(화이트리스트 방식): 등록된 명령어만 사용할 수 있습니다. 보안이 중요한 운영 환경에 적합합니다.
    - **금지**(블랙리스트 방식): 등록된 명령어의 사용을 차단합니다. `shutdown`, `reboot` 등 위험한 명령어만 선별적으로 차단할 때 유용합니다.

    명령어를 입력하고 **+ 추가**를 클릭하면 목록에 등록됩니다.

    > [!WARNING]
    > SSH, TELNET, SFTP, SCP, FTP 등의 우회 접속 명령어는 명령어 정책 등록과 관계없이 항상 차단됩니다.

7. 설정을 마쳤다면 **저장**을 클릭하세요. 정책 관리 목록에 생성한 정책이 나타납니다.

> [!NOTE]
> 정책이 여러 개인 경우 **순서 변경**을 클릭해 우선순위를 조정할 수 있습니다. 같은 사용자에게 여러 정책이 적용될 때 우선순위가 높은 정책이 먼저 적용됩니다.

## 인스턴스에 접속하기

정책이 설정되면 사용자는 자신에게 허용된 인스턴스에 웹 터미널로 접속할 수 있습니다.

1. NHN Cloud 콘솔에서 **Security > NHN Bastion**의 **인스턴스 연결** 탭을 클릭하세요. 현재 사용자에게 접근이 허용된 인스턴스 목록이 표시됩니다.

2. 접속할 인스턴스의 **연결** 버튼을 클릭하세요. **인스턴스 연결** 모달 창이 나타납니다.

3. **웹 터미널 선택**에서 접속에 사용할 웹 터미널을 선택합니다. 인스턴스와 SSH 통신이 가능한 웹 터미널을 선택해야 합니다.

4. 대상 인스턴스에 IP가 여러 개인 경우 **IP** 드롭다운에서 접근할 IP를 선택합니다.

5. 인증 방식을 선택하고 인증 정보를 입력합니다.

    - **SSH 키**: **ID**에 운영체제 계정을 입력하고, **파일 선택**을 클릭해 인스턴스 생성 시 설정한 키 파일(.pem)을 업로드합니다.
    - **비밀번호**: **ID**에 운영체제 계정을 입력하고, 비밀번호를 입력합니다. 운영체제에서 비밀번호 인증이 활성화되어 있어야 합니다.
    - **임시 키**: **ID**에 운영체제 계정을 입력합니다. 일회성으로 발급되는 임시 SSH 키를 사용하므로 별도의 키 관리가 필요 없고, 키 유출 시에도 침해 사고를 방지할 수 있습니다. 이 방식을 사용하려면 미리 대상 인스턴스에서 스크립트를 실행해야 합니다. 자세한 내용은 [NHN Bastion 콘솔 사용 가이드](https://docs.nhncloud.com/ko/Security/NHN%20Bastion/ko/console-guide/)를 참고하세요.

6. **접속**을 클릭하면 브라우저에서 웹 터미널이 열리고 인스턴스에 SSH로 연결됩니다.

## 접속 이력 확인하기

NHN Bastion은 모든 접속과 명령어 사용을 자동으로 기록합니다. 보안 감사나 장애 추적에 활용할 수 있습니다.

### 실시간 세션 모니터링

1. NHN Cloud 콘솔에서 **Security > NHN Bastion**의 **이력 관리** 탭을 클릭한 뒤 **실시간 세션** 탭을 선택하세요.

2. 현재 인스턴스에 연결되어 있는 세션 목록이 표시됩니다. 각 세션의 사용자 이름, ID, 이메일, 인스턴스 IP, 접속 시작 시간을 확인할 수 있습니다.

3. 비정상적인 세션이 발견되면 해당 세션의 **세션 차단** 버튼을 클릭해 즉시 종료할 수 있습니다. **상세 보기** 버튼을 클릭하면 세션의 상세 정보를 확인할 수 있습니다.

### 사용자 접근 이력 조회

1. NHN Cloud 콘솔에서 **Security > NHN Bastion**의 **이력 관리** 탭을 클릭한 뒤 **사용자 접근 이력** 탭을 선택하세요.

2. 검색 조건과 접속 시간 범위를 지정해 원하는 이력을 조회합니다.

3. 특정 이력을 클릭하면 세션 정보와 명령어 사용 로그를 상세하게 확인할 수 있습니다.

> [!NOTE]
> 이력은 최대 6개월간 보관됩니다. 6개월 이상 보관이 필요하면 **환경 설정 > 로그 관리**에서 Object Storage 백업을 설정하세요.

## 응용하기

- **명령어 통제 강화**: 운영 환경에서는 **허용**(화이트리스트 방식)으로 `ls`, `cat`, `tail` 등 필요한 명령어만 등록하면 최소 권한 원칙을 적용할 수 있습니다.
- **자동 등록 활용**: 인스턴스를 빈번하게 생성하고 삭제하는 환경이라면 **자원 관리 > 인스턴스 관리**에서 **자동 등록**을 활성화하세요. 인스턴스 변경 사항이 자동으로 반영되어 등록 누락을 방지할 수 있습니다.
- **사용자 그룹 활용**: **사용자 관리 > 그룹** 탭에서 역할이나 부서별로 사용자 그룹을 만들어 두면, 정책 생성 시 개별 사용자 대신 그룹 단위로 접근 주체를 등록할 수 있어 관리가 간편합니다.
- **세션 차단 정책**: **환경 설정 > 세션 차단**에서 금지 명령어를 일정 횟수 이상 사용하면 세션을 자동으로 차단하도록 설정할 수 있습니다. **계정 잠금**과 함께 사용하면 반복적인 위반 행위에 대해 계정을 자동으로 잠글 수 있습니다.

## 정리하기

실습 목적으로 따라한 경우, 더 이상 사용하지 않는 리소스를 삭제해 불필요한 과금을 방지합니다.

1. NHN Cloud 콘솔에서 **Security > NHN Bastion**의 **정책 관리** 탭에서 생성한 정책을 선택하고 **삭제**를 클릭하세요.

2. **자원 관리** > **인스턴스 관리** 탭에서 등록한 인스턴스를 선택하고 **삭제**를 클릭하세요. 자동 등록을 활성화한 경우 토글을 비활성화합니다.

> [!WARNING]
> NHN Bastion 서비스 자체를 삭제하려면 **환경 설정** 탭 하단의 **NHN Bastion 삭제**를 클릭합니다. 이 작업은 웹 터미널, 정책, 로그 등 생성된 모든 자원을 영구 삭제하며 복구할 수 없습니다.

## 용어 정리

| 용어 | 설명 |
|---|---|
| 웹 터미널 | NHN Bastion이 제공하는 브라우저 기반 SSH 접속 환경. 인스턴스에 대한 SSH 프록시 역할을 합니다. |
| 접근 통제 정책 | 사용자별로 접근 가능한 인스턴스와 사용 가능한 명령어를 정의하는 규칙 |
| 화이트리스트 | 등록된 항목만 허용하고 나머지는 차단하는 방식 |
| 블랙리스트 | 등록된 항목만 차단하고 나머지는 허용하는 방식 |
