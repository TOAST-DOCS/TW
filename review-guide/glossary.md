> **목적**: NHN Cloud 기술 문서 검수 시 용어 표기 일관성 확보를 위한 공식 용어 기준 파일입니다.
> 
> **구성**: [1. NHN Cloud 서비스 용어](#1-nhn-cloud-서비스-용어) | [2. 일반 기술 용어](#2-일반-기술-용어)
> 
> **활용 지침**:
> - `한국어` 열: 한국어 문서의 공식 표기 기준
> - `영어` 열: 영어 문서의 공식 표기 기준
> - `일본어` 열: 일본어 문서의 공식 표기 기준
> - `약어` 열: 약어 사용 시 첫 등장에는 전체 용어와 함께 표기

## 2. 일반 기술 용어

NHN Cloud 기술 문서에서 사용되는 일반 기술 용어의 공식 표기 기준입니다.

| 한국어 | 영어 | 일본어 | 약어 | 한국어 정의 |
|--------|------|--------|------|-------------|

| 포트 포워딩 | port forwarding | ポートフォワーディング |  | 컴퓨터 네트워크에서 패킷이 네트워크 게이트웨이를 통과하는 동안 하나의 IP 주소와 포트 번호로 결합된 통신 요청을 다른 곳으로 넘겨 주는 네트워크 주소를 변환해 주는 것 |
| 프라이빗 IP | private IP | プライベートIP |  | 회사 등 조직이나 일반 가정 내부 네트워크에서 사용하는 비공개된 IP 주소로 라우터를 통해 외부 네트워크와 통신함 |
| 프라이빗 네트워크 | private network | プライベートネットワーク |  | 인터넷 주소 구조에서 사설 네트워크를 정의하는 IP 영역으로 표기된 네트워크 |
| 프로비저닝 | provisioning | プロビジョニング |  | 사용자 또는 비즈니스의 요구에 맞추어 서비스를 제공할 수 있도록 미리 자원을 할당하고 배치하는 것 |
| 프로젝트 | project | プロジェクト |  | 조직 내에서 일정 단위로 서비스 이용을 관리하기 위해 생성하는 그룹 |
| 프로젝트 멤버 | project member | プロジェクトメンバー |  | 프로젝트에 소속된 구성원 |
| 프로젝트 피어링 | project peering | プロジェクトピアリング |  | 동일 리전, 다른 프로젝트의 서로 다른 두 개의 VPC를 연결하는 기능 |
| 플로팅 IP | floating IP | フローティングIP |  | 외부 네트워크와 통신할 수 있도록 별도 요청을 통해 지정된 네트워크로부터 할당 받는 IP 주소 |
| 피어 | peer | ピア |  | 특정 네트워크에 속해 있고 모두 동일한 기능을 가진 기기로 이는 하드웨어 장비, 소프트웨어 프로그램, 노드, 또는 사용자가 될 수 있음 |
| 피어링 | peering | ピアリング |  | 서로 다른 두 VPC를 연결하는 기능. 피어링 게이트웨이에서는 동일 리전, 동일 프로젝트의 서로 다른 두 개의 VPC를 연결하는 기능을 뜻함 |
| 하이브리드 클라우드 | hybrid cloud | ハイブリッドクラウド |  | 단일 애플리케이션을 위해 프라이빗 클라우드와 퍼블릭 클라우드를 결합하여 사용하는 클라우드 컴퓨팅 전략 |
| 하이퍼바이저 | hypervisor | ハイパーバイザー |  | 가상화를 구현하기 위한 기반이 되는 기술로 하나의 컴퓨터에서 다수의 서로 다른 운영체제를 동시에 실행하기 위한 논리적 계층 |
| 허브 앤 스포크 | Hub-Spoke | ハブアンドスポーク |  | 중앙 허브(Hub) 네트워크에 여러 개의 스포크(Spoke) 네트워크를 연결하여 공통 서비스와 트래픽을 중앙에서 통합 관리하는 네트워크 설계 방식 |
| 헬스 체크 | health check | ヘルスチェック |  | 설정한 값에 따라 Pool 내에 속한 엔드포인트에 대해 접근성을 확인하는 기능 |
| 확장 | scale-out | 拡張 |  | Auto Scale 서비스에서 구동 인스턴스 수를 늘리는 것 |
| 회원 | member | 会員 |  | NHN Cloud 서비스에 가입한 회원. 일반적으로 'NHN Cloud 계정'과 동의어 |
